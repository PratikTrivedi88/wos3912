# # ❄️ Whiteout Survival Event Hub

A static, JSON-driven event hub for Whiteout Survival alliances.

## Features
- Frost/WoS-style animated UI
- Local + UTC clocks
- Live event countdowns
- Alliance rotation section
- Full event calendar with filters
- Admin panel for editing events
- Data persistence via localStorage
- Mobile responsive
- No backend required (GitHub Pages/Render ready)

## Deployment
1. Clone or download this repo.
2. Push to GitHub.
3. Enable GitHub Pages in repo settings.
4. Your hub is live!
